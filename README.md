# Haut du corps 8 & 13 kg

Programme maison pour le haut du corps (torse, épaules, abdos) avec deux haltères de 8 kg et une kettlebell de 13 kg.
3 séances par semaine, exercices animés, carte des muscles ciblés, minuteur de repos.

Ouvre le site dans Safari, puis Partager → « Sur l'écran d'accueil ».
